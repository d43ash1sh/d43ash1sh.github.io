## Overview

This repository powers the official portfolio website of **Debashish Bordoloi**, deployed at [https://d43ash1sh.github.io/](https://d43ash1sh.github.io/). Built with Next.js App Router, React 19, and Tailwind CSS v4, it presents verified technical projects, security research, publications, and professional background.

## Sections & Features

1. **Bilingual Localization (English & Assamese)**:
   - Full toggle between English and Assamese (`অসমীয়া`) powered by `LanguageProvider`.
2. **Hero Section**:
   - Availability status, profile avatar, verified badge, and animated roles.
3. **Contact & Socials**:
   - Direct email, real-time IST clock, location, resume PDF, and direct links to LinkedIn, GitHub, Instagram, HackerOne, Bugcrowd, and X.
4. **Skills & Tools**:
   - Categorized skills spanning Frontend, Backend & APIs, Databases, Application Security, Tools & Workflow, and AI & Research.
5. **Featured Projects**:
   - **OrganLink**: Academic healthcare registry and transparent matching research prototype.
   - **Nya Search (ঞ)**: Regional-language-aware AI search engine with source-grounded answers.
   - **Agent Search Engine**: Agent-native crawl, extraction & hybrid retrieval engine with Python, FastAPI, Playwright, pgvector, and MCP.
   - **CubeCube**: Interactive 3D Rubik's cube solver and tutor with Three.js.
   - **Adi Voice Project**: Speech corpus platform preserving the indigenous Adi language.
   - **AuthHub**, **ClipNinja**, **Decentralized Storage System**, **SpeedPulse**, **ADTU Confessions**, **RGU Library Card Generator**, and **Subz**.
6. **About, Highlights & Education**:
   - Academic background (M.Tech CSE at Rajiv Gandhi University, MCA, BCA).
   - Security researcher achievements (Bugcrowd, HackerOne, OWASP Chapter Leader, CNCF Guwahati).
   - Peer-reviewed research publication in the Journal of Information and Optimization Sciences (JIOS, DOI: `10.47974/JIOS-1981`).
   - ICRTMC-2026 conference presentation at Jamia Millia Islamia.
   - Administrative architecture & reverse engineering audit with REA.
7. **Interactive Hacker Terminal (DebOS)**:
   - Press `` ` `` (backtick) or `Esc` anywhere on the site to toggle the terminal.
   - Commands: `help`, `whoami`, `skills`, `projects`, `contact`, `sudo hack-website`, `clear`, `exit`.
8. **AI Assistant (AI Debashish)**:
   - Interactive chatbot answering questions about projects, security research, and technical background.

## Local Development

```bash
# Clone the repository
git clone https://github.com/d43ash1sh/d43ash1sh.github.io.git
cd d43ash1sh.github.io

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Quality Checks & Build

```bash
# Type check
npx tsc --noEmit

# Lint
npm run lint

# Production build & static export
npm run build
```
